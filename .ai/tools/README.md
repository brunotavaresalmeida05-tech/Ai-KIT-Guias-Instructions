# TOOLS — Gateway de Acções para IA

## EXPLORER — Exploração de Ficheiros
Permite ao agente navegar a estrutura do projecto.
Uso: "Usa o explorer para ver a estrutura de [pasta]"

## CONTEXT — Estrutura Semântica
Carrega contexto relevante para a tarefa actual.
Uso: "Carrega o contexto de [feature/módulo]"

## PLAN — Gestão de Plano
Cria e acompanha o plano de execução.
Uso: "Actualiza o plano com [nova tarefa/estado]"

## AGENTS — Orquestração
Descobre e activa agentes especializados.
Uso: "Activa o agente [nome] para [tarefa]"

## SKILLS — Gestão de Competências
Carrega skills sob demanda.
Uso: "Carrega a skill [nome] para [tarefa]"

## SYNC — Sincronização
Sincroniza contexto com ferramentas externas (GitHub, Jira, etc.)
Uso: "Sincroniza o estado com [ferramenta]"

## LÓGICA/SINTAXE — Validação
Valida se a lógica do código corresponde à intenção.
Uso: "Valida a lógica de [função/módulo]"
Nota: Sintaxe correcta ≠ Lógica correcta. Este tool força a validação semântica.
