# Anthropic Skills Integration

## Overview
Integration of Anthropics/skills - Agent skills framework with MCP builders, document manipulation, and specialized workflows.

## Skills Integrated
- mcp-builder - MCP server creation and configuration
- context-router - Skill selection and routing
- code-review - Automated code review with findings
- simplify - Code simplification and reuse detection
- security-review - Security-focused code review

## Key Components
- YAML skill schema with frontmatter
- Skill execution via /skill-name commands
- Context-aware skill routing
- Verification and validation commands
